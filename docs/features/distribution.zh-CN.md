# 订阅分发（production 分支）

这是本分支独立的发货与续期业务。原有机场、资源订阅和 `/c/` 分享功能保留；新链接使用 `/d/<token>`，不能通过旧分享接口绕过限制。

## 设置与发放

1. 先在原有订阅管理中准备资源订阅。
2. 进入 `/admin/distribution` 的「分发设置」，填写订阅域名与公开首页完整地址。公开首页默认是 `/`，管理员登录是 `/admin/login`。配置了 Web Base Path 时，页面地址仍带此前缀，`/api/` 和 `/d/` 不带。
3. 确认后端有可用的 GeoLite2-City 数据库；国家库不能用于城市授权。可选的 ip2region 与 ipdata 城市兜底见[配置说明](../configuration.zh-CN.md#分发城市定位兜底production-分支)。反代必须正确传递真实 IP，后端只信任明确的代理地址；不要对分发链接或公开 API 缓存响应，代理访问日志也应隐藏 token。
4. 生成单条或批量链接，选择资源订阅，导出给发货系统。批次标识可用于幂等重试，每批最多 100 条。
5. 用户在客户端导入链接，手动设置每日更新（1440 分钟），订阅域名直连。服务端返回的更新间隔为 24 小时；客户端是否遵循取决于客户端设置。

批量生成链接或付费卡密时，名称作为前缀，自动追加三位序号，例如 `9月-001` 至 `9月-100`；单条生成保留填写的名称。已有名称不自动更改，同批次重试仍返回原记录。订阅列表只展示名称与编号，完整批次标识可在「管理」详情查看和手动复制。

后台可查询、导出、停用、重新启用链接，删除，或更换遗失的链接。更换只轮换 token，不改变身份 ID、权益和允许城市。新生成链接快照保存当时的试用天数，后续修改默认时长不影响已发放链接。

列表每行直接提供「删除」，勾选后可「删除所选」，均需确认。删除复用原永久销毁状态（API 值仍为 `revoked`）：原链接永久失效，不能恢复、改名、换资源、轮换或兑换；默认「未删除」列表隐藏它，可筛选「已删除」查看只读详情和访问记录，但不再提供旧链接复制或导出。兑换记录中的订阅仍可点击查看，并标记已删除；付费卡原绑定保留，不会重新变成可用卡。批量删除为原子操作，任意 ID 不存在时整批失败，重复删除安全。原批次有已删除链接时重新生成返回冲突，请使用新批次。停用仍可重新启用，不等于删除。

订阅列表的名称可原位编辑：点击名称或铅笔图标，选择「保存」（或 Enter）提交，「取消」（或 Esc）放弃；不会在失焦时自动保存。失败会保留输入并显示错误。快捷保存只提交名称，不改变链接、资源、有效期或城市；已删除链接不能改名。其他设置仍从「管理」进入。

列表每行提供「复制链接」，无需进入详情；成功后按钮短暂显示「已复制」，浏览器禁止写入剪贴板时才弹出已选中链接的手动复制框。「管理」详情仍保留「复制订阅链接」，保存后在操作按钮旁明确显示成功或失败。除已删除链接外，激活前后均可更换资源订阅；下次拉取使用新资源池，链接、试用起点、有效期、权益和允许城市不变。无效或已删除资源不能选用；如果生成配置期间资源池发生切换，最终授权时会丢弃旧资源的结果。状态通过图标、底色和文字共同区分。

客服定位时，可直接在「搜索订阅链接、名称或批次」中粘贴客户的完整 `/d/<token>` 链接。支持 `?client=mihomo` 等格式参数、片段及首尾空白，也支持完整的 64 位 token。链接／token 使用索引中的凭据摘要精确匹配，不会混入名称碰巧包含该 token 的其他客户；名称、批次仍支持文字搜索。现有状态筛选继续生效：查询已删除链接时选择「已删除」，返回只读记录。重置后旧 token 不再保留，因此旧链接无法定位，需使用当前链接或名称／批次。搜索不会激活、续期或登记城市。界面将非空订阅搜索放在需管理员鉴权的 POST 请求体中，不把客户链接拼入查询 URL；请勿对这些接口启用请求体日志。

「复制链接」默认使用自动识别（不带 `client` 参数）。旁边的「格式」菜单可直接选择并复制自动识别、Clash、Mihomo、Surge 或 V2Ray 链接。指定格式只是在同一条 `/d/<token>` 链接上添加 `?client=clash`、`mihomo`、`surge` 或 `v2ray`，不生成新用户凭据，也不绕过 UA、激活、城市、有效期和停用／删除检查。批量导出仍为自动识别链接；剪贴板受限时，手动复制框保留所选格式。

卡密列表每行可直接「复制卡密」，成功后显示反馈；剪贴板不可用时弹出已选中的卡密供手动复制。生成卡密、获取本期免费卡密和导出弹窗展示纯卡密，每行一条，「复制全部卡密」不会夹带名称；「下载文本」仍保留名称与卡密，以制表符分隔。订阅链接导出保持原有名称加链接的格式。剪贴板不可用时，会选中对应的待复制内容。

## 拉取与地区规则

在「分发设置 → 每条订阅的地区上限」选择 1 或 2 个城市，默认 2；测试时可临时设为 1，测试后恢复为 2。保存立即生效，包含已开始生成但尚未完成授权的拉取和地区申请审核。列表、详情及公开查询显示当前上限。若未删除的订阅已绑定超过新上限的城市，本次保存整体拒绝（`region_limit_conflict`），不删除绑定、不暗中保留超额通行权限；请保留原上限。升级与省略新字段的旧接口请求不会重置已保存的设置。

定位依次使用有容量上限的 24 小时 IP 缓存、GeoLite2、可选的 IPv4／IPv6 ip2region 离线库，最后才调用可选的服务端 ipdata。只有信息不完整才继续兜底，明确境外的结果不会反复换源直到放行。通过已安装的城市库，将各来源名称统一到原有 GeoNames 编号；未知或歧义映射、已知位置冲突均拒绝且不占地区名额。外部服务超时或额度用完不影响完整的本地定位，也不会放行无法定位的用户。上线前仍需核对用户真实城市，数据库结果不是本人位置证明。

只有白名单客户端发起有效 GET、生成非空可用配置并通过最终授权检查后，才登记激活与城市。浏览器访问跳转公开页；HEAD、非白名单 UA、非中国大陆 IP、无法定位城市、空资源及转换失败均不会激活。

默认 UA 白名单包含 Clash Meta for Android 的 `ClashMetaForAndroid/…`，可直接导入原链接，自动返回 Clash YAML。升级时仅给仍使用旧版完整默认规则的实例补上此标识；管理员自定义正则保持不变，需要时在「分发设置」自行加入此明确标识。它不会绕过 IP、地区、有效期或链接状态检查。若客户端把 `Unsupported subscription client` 报成 YAML 解析错误，先检查访问记录是否为 `ua_denied`，不要直接放开所有 UA。

默认首次试用 15 天，可设 1–365 天。首次有效拉取登记第一个城市；默认上限为 2 时，第二个有效城市自动登记；超出所设上限的城市只收到不可用提示节点。停用、销毁、境外与无法识别城市同样不返回真实节点。

停用及其他拒绝提示将原因、下一步操作、公开首页网址分别放在独立提示节点中，不再挤在一个名称里。停用显示「订阅已停用」「请联系管理员恢复」；删除显示「订阅链接已失效」「请联系管理员」。这些提示不会启用到期降级资源，也不改变已配置的到期文案。

正常和拒绝拉取时，配置标题与下载文件名均使用分发链接的名称；拒绝或到期文案只出现在提示节点中，不作为订阅名称。有些客户端会保留首次导入时的名称：如果旧版本已把拒绝提示保存为名称，需要在客户端手动改名一次。更新订阅会替换内容，但服务端无法强制所有客户端修改本地名称。

分发链接每次拉取都跟随所选资源订阅的「实时获取用量信息」开关。关闭时不刷新机场用量，也不发送 `subscription-userinfo`，即使存在缓存用量也不显示；开启时沿用现有机场用量刷新和汇总逻辑，并返回用量信息，相关机场需开启用量获取且上游提供数据。流量数值代表共享资源池，不是每个用户的独立额度。到期字段使用分发链接自身的有效期，不沿用机场到期时间；永久权益不发送到期字段。关闭开关后客户端原生到期栏也可能不显示，仍可在公开首页查询有效期。浏览器／HEAD 探测、拒绝访问和到期提示（含降级节点）不刷新或返回用量。原有 `/c/` 分享行为不变。保存开关后，下次客户端更新即生效；若客户端保留旧元数据，可能需要在本地清理。

IP 城市和 UA 是共享风险控制，不是本人身份认证：同城共享、伪造 UA 或抢先激活仍有可能，运营商定位也可能误判。允许本人多设备、换网；当前没有物理设备数限制，UA 数和 IP 数不等于设备数。不控制已经下载的节点配置。

用户在新城市被拒绝后，到公开首页输入链接查询状态，选择最近 7 天的拒绝记录，填写理由，可选联系方式。每次申请一个城市，每条链接最多一个待审申请、24 小时最多 3 次新申请。后台批准时若已达上限，须选择替换哪个原有城市，总数不超过当前设置；拒绝时填写回复。用户查询状态可以看到结果，无需 TG 登录。

后台顶部通知铃铛和「地区申请」标签显示待审核数量；铃铛内的入口直接打开待审核列表。数量在进入后台、返回窗口及页面可见时每 30 秒更新，审核或删除订阅后立即重新查询；标记通知已读、清空通知历史不会清除待办。网络失败会显示重试提醒，不会把未知数量当成零。此提醒仅在登录后的后台生效，不发送外部推送。公开页查询后会在返回窗口及页面可见时每 60 秒更新状态和地区上限；升级前已打开的旧页面需重新加载一次。

## 到期与续期

卡密列表支持粘贴完整卡密精准搜索，同时保留名称／批次搜索、状态筛选和分页。新短码支持大小写、带／不带横杠或 ASCII 空白，旧 64 位码继续支持；不支持按卡密片段查找。完整卡密通过索引摘要匹配，不会误匹配同名卡，不扫描全部卡密密文，不触发兑换。已删除卡不会出现在搜索列表。界面通过管理员鉴权的 POST `/api/v1/distribution/cards/search` 请求体传递关键词，避免卡密进入查询 URL；不要启用请求体日志。

| 权益 | 规则 |
| --- | --- |
| 首次试用 | 首次有效拉取开始，默认 15 天 |
| 免费卡密 | 默认每 7 天一个周期，兑换后从当时起生效 7 天；允许多人兑换，同一链接同周期只生效一次 |
| 三个月 | 从当前到期时间与兑换时间中较晚者延长 3 个日历月 |
| 一年 | 按同样规则延长 1 年 |
| 永久 | 没有权益到期时间 |

月末按目标月最后一天截断。免费续期不叠加，不缩短尚未到期的试用或付费权益；同张付费卡密只绑定一个订阅 ID，重复请求返回原兑换结果，不再次延长。兑换前需先激活。付费卡密的「兑换截止时间」与兑换后的权益时长不同。

公开兑换页会区分实际新增权益与重复兑换：重复使用同周期免费卡（含补发的新码）或同张付费卡时，显示原兑换时间和「本次未再次续期」，不再显示新的续期成功。操作后重新查询当前订阅状态；若查询失败，隐藏旧状态并提示重新查询，兑换结果不会被误报为失败。

「兑换记录」以订阅名称、卡密名称为主，编号为辅助信息，两列均可点击打开对应管理弹窗。名称随管理端改名更新；记录中的权益类型、兑换前后到期时间仍是原兑换事实。已删除卡密仍显示原名称及「已删除」，点击只读查看，不提供旧码或恢复操作；关联记录缺失时退回显示类型与编号，兑换记录本身不丢失。

新生成的付费和免费卡密采用 16 位安全随机字母数字（80 位随机强度），分四组显示，例如 `K7MP-9XRT-4WQN-8HDC`。兑换不区分大小写，可省略连字符和 ASCII 空白。旧 64 位卡密继续有效，不会改写；已生成的本期免费卡密和同批次重试仍返回原卡。只有新卡和新的免费周期使用短格式，订阅链接 token 不变。

「获取本期免费卡密」按 UTC 周期起点计算当前周期，第一次请求生成，后续请求返回同一张。无需定时任务；外部系统可每周期调用此接口取新码。停用本期免费卡密不会自动生成替代码。删除后，普通获取不会恢复旧码或自动生成；界面会要求确认「补发本期免费卡密」，生成新码后，同一订阅本期仍只能获得一次免费权益。重复补发返回当前有效记录（若已停用则仍保持停用）。下一周期正常生成新卡。不要在运行中随意改变周期起点或轮换天数，否则会改变周期边界与卡密。

卡密列表直接提供复制、编辑、启用／停用、导出和删除，可筛选启用状态、勾选批量删除。未兑换的付费卡可修改名称、权益类型（三个月／一年／永久）和兑换截止时间，卡密本身不变；已兑换的付费卡可改名称和截止时间，但不可变更权益类型或绑定对象。需要纠正已发放权益时，请到对应订阅链接的「管理」调整有效期。免费卡可改名称，不可改为付费卡或单独更改周期截止时间。

删除须确认，删除后卡密立即失效并从列表移除，不能通过启用或原批次重试恢复；数据库保留删除标记、原绑定及兑换记录，不撤回已发放权益。批量删除为原子操作，任意 ID 不存在时整批失败。原批次有已删除记录时重新生成返回冲突，请使用新的批次标识。删除不等于停用：停用可以再次启用，删除不能恢复原码。

到期后，可返回选定资源订阅中的降级节点，或只返回提示节点及续订页面地址。降级节点只适用于通过 IP／城市校验的到期请求，超出地区上限的城市不能获取。降级只取节点，不继承原模板和远程包含。续订在公开首页输入原链接与卡密，成功后更新客户端即可，链接保持不变。

在「分发设置 → 到期提示节点」逐条填写文案，支持新增、删除和上下排序，共 1–10 条，每条最多 200 个字符且不得包含换行或控制字符。一条文案生成一个不可连接的提示节点，降级节点（若有）排列在提示后面；不会给每条文案自动追加网址。`{portal}` 会替换为公开首页完整地址，例如依次填写「订阅已到期」「请领取卡密续订」「{portal}」。建议短句，客户端仍可能截断过长的名称；重复名称会自动追加序号。保存后在客户端下次更新时生效，续订后提示节点消失。其他拒绝访问提示不受此设置影响。

升级保留旧文案，将原先拼在末尾的网址拆成独立节点；后台首次保存列表后按新列表输出。原单条 `expired_message` 字段保留兼容，新字段为 `expired_messages`；已有列表不会被省略新字段的旧接口请求清空。

## 客户端与直连

Clash、Mihomo、Surge 原生生成配置；Loon 和 Shadowrocket 自动识别时返回 Base64 编码的通用节点 URI 列表（即 `v2ray` 输出，并非仅供 V2Ray 使用），不需要 Sub-Store。Loon 因而与原分享自动识别的可用格式一致。显式指定 `?client=loon` 仍表示转换为 Loon 专用配置，该方式与 Stash、Quantumult X、sing-box 等扩展格式需要原有 Sub-Store sidecar 配置。只有能够生成有效资源的格式才会激活。选择格式不能让客户端支持其本身不支持的节点协议。

填写订阅域名后，Clash／Mihomo／Surge 配置优先加入该域名的 DIRECT 规则。其他格式可能仅为节点列表，需用户手动配置直连；首次导入前也需手动保证订阅拉取直连。Surge／Surfboard 的托管更新地址保持在分发链接上，不采用资源模板中的旧分享地址，也不向外部续订网站发送 token。

## API 与运维

详见 [API 参考](../../skill-sublinkpro/reference/api.md#subscription-distribution-production-fork)。管理接口沿用 `X-API-Key` 或管理员 JWT；公开页接口不携带管理员令牌。无需新增 `config.yaml` 键，业务设置保存在独立的 `distribution_*` 数据表。

公开接口每实例按 IP 限速：自助页 API 30 次／分钟，拉取 120 次／分钟；超限返回 429。每条链接保留最近 200 次访问，后台详情展示最近 20 次。兑换记录和审批记录保留；公开状态不返回原始 IP、UA 或管理员访问凭据。

链接与卡密属于秘密，后台为导出而加密保存；使用现有 `SUBLINK_API_ENCRYPTION_KEY`。备份必须同时保存完整数据库与实际使用的加密密钥，使用环境变量注入密钥时不能只备份数据库。旧版导入工具不支持分发数据，有分发记录的源或目标数据库会在清空数据前拒绝导入；请使用完整数据库备份恢复。SQLite 备份应停机或采用一致性快照，外部 MySQL/PostgreSQL 应使用其原生备份工具。

开发使用 Vite + Air，先验证界面，再单独部署生产；不要把开发数据目录直接挂给生产。回退旧程序前先备份，旧程序无法提供新的分发入口。
